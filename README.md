# AAPL Historical Stock Market Analysis

This project analyzes historical Apple Inc. (AAPL) stock market data using Python, Pandas, Matplotlib, and yfinance.

The analysis covers **January 2, 2020 to August 10, 2026**, with 1,659 trading-day observations.

## Project Focus

The project applies:

* Data exploration and quality assessment
* Pandas data transformation
* Time-series analysis
* Feature engineering
* Moving-average analysis
* Monthly performance analysis
* Volatility analysis
* Data visualization

## Features Created

* Daily Price Change
* Percentage Price Change
* 7-Day Moving Average
* 30-Day Moving Average
* Monthly Return

## Key Findings

* AAPL's closing price increased by approximately **326.53%** over the analysis period.
* The average monthly return was **+2.12%**.
* Daily return volatility was approximately **1.98%**.
* The highest monthly return was **+21.66% in August 2020**.
* The lowest monthly return was **-12.23% in December 2022**.
* The 7-day moving average captured short-term price movements more closely, while the 30-day moving average provided a smoother view of the broader trend.
* Trading volume showed substantial variation throughout the period, including several significant spikes.
